# Digital World Sales Analysis

## Project Overview
This project presents an end-to-end sales analytics workflow. The dataset was initially explored using Microsoft Excel for exploratory data analysis (EDA), analyzed using SQL to answer business questions, and visualized in Power BI through an interactive dashboard.

The objective of this project is to analyze sales performance across product categories, products, and suppliers, and to uncover insights that support data-driven business decisions.

---

## Tools & Technologies
- **Microsoft Excel** – Data exploration and EDA  
- **SQL** – Data cleaning, aggregation, and analysis  
- **Power BI** – Data modeling and visualization  

---

## Project Workflow
1. **Data Exploration (Excel)**  
   - Reviewed the dataset structure  
   - Performed basic EDA to understand trends, distributions, and data quality  

2. **Data Analysis (SQL)**  
   - Wrote SQL queries to analyze sales performance  
   - Calculated key metrics such as total sales, quantity sold, and revenue by category, product, and supplier  

3. **Data Visualization (Power BI)**  
   - Connected the SQL database directly to Power BI  
   - Built an interactive dashboard to communicate insights clearly  

---

## Key Insights
- eBikes generated the highest total sales and quantity sold  
- Racing Bikes and Mountain Bikes were strong revenue contributors  
- A small number of suppliers accounted for a large share of total gross sales  
- Certain individual products significantly outperformed others in revenue
